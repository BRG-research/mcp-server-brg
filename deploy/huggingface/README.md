# BRG MCP server

The [BRG MCP server](https://github.com/BRG-research/mcp-server-brg) over Streamable HTTP at `/mcp`,
for MCP clients that cannot start it locally, such as the CAS website's BRG terminal through the Claude
API's MCP connector. This Space is deployed from GitHub on every push to `main`. Do not edit it here.
