§ 40. Analytische Einleitung.

223

Die Einmauerung bei A liefert eine Reaktion R₁ und ein Kräftepaar mit dem Momente m₁, die Einmauerung bei B eine Reaktion R₂ und ein Kräftepaar mit dem Momente m₂. Die Reaktion in C sei mit R₃ bezeichnet. Sämmtliche Reaktionen seien nach aufwärts gerichtet eingeführt.

Aus den Gleichgewichtsbedingungen folgen die beiden Gleichungen:

(a) $$\left\{ \begin{array}{l} R_1 + R_2 + R_3 = P, \\ m_1 + m_2 + 4R_1a + 2R_3a = 3Pa. \end{array} \right.$$

Die beiden Gleichgewichtsbedingungen enthalten fünf Unbekannte den fünf Lagern entsprechend, die sich bei Ersetzung der Einmauerungen durch je zwei Lager ergeben. Durch die elastische Linie sind somit drei weitere Gleichungen herzuleiten.

Der Punkt A sei zum Nullpunkt der x-Achse angenommen und die positive x-Achse durch B gelegt.

Durch die Einmauerungsstellen A und B, das weitere Lager in C und durch die Kraft P ist der Balken in drei Intervalle geteilt. Für dieselben ergeben sich die Momente:

für 0 < x < a: M = m₁ + R₁x,

für a < x < 2a: M = m₁ + R₁x - P(x - a),

für 2a < x < 4a: M = m₁ + R₁x - P(x - a) + R₂(x - 2a).

In dem Intervalle 0 < x < a ist die Differentialgleichung der elastischen Linie:

$$JE \frac{d^2y}{dx^2} = -m_1 - R_1x.$$

Durch deren Integration folgt:

$$JE \frac{dy}{dx} = -m_1x - \frac{1}{2}R_1x^2 + C_1,$$

$$JEy = -\frac{1}{2}m_1x^2 - \frac{1}{6}R_1x^3 + C_1x + C_2.$$

Da nun aber für x = 0 sein muß:

$$y = 0 \text{ und } \frac{dy}{dx} = 0,$$

so verschwinden die beiden Integrationskonstanten C₁ und C₂:

$$C_1 = 0, \quad C_2 = 0,$$

und die Gleichung der elastischen Linie in dem ersten Intervall wird:

(b) $$JEy = -\frac{1}{2}m_1x^2 - \frac{1}{6}R_1x^3.$$
