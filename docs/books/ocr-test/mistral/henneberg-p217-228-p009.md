Aus den Gleichungen (e) folgt:

$$R _ { 1 } = { \frac { 1 9 } { 3 2 } } P ,$$

$$R _ { 3 } = { \frac { 1 } { 2 } } P ,$$

$$m _ { 1 } = - { \frac { 5 } { 1 6 } } P a ,$$

und sodann aus den Gleichungen (a):

$$R _ { 2 } = - { \frac { 3 } { 3 2 } } P ,$$

$$m _ { 2 } = - { \frac { 1 } { 1 6 } } P a ,$$

doch wäre die Bestimmung von $R _ { 2 }$ und $m _ { 2 }$ nicht erforderlich gewesen, da in den Ausdrücken für das Biegungsmoment nur $R _ { 1 } , R _ { 3 }$ und $m _ { 1 }$ vorkommen.

Das Biegungsmoment in den verschiedenen Intervallen wird jetzt

für $0 < x < a$ : $M = - { \frac { 5 } { 1 6 } } P a + { \frac { 1 9 } { 3 2 } } P x ,$

für $a < x < 2 a$ : $M = - { \frac { 5 } { 1 6 } } P a + { \frac { 1 9 } { 3 2 } } P x - P ( x - a ) ,$

für $2 a < x < 4 a$ : $M = - { \frac { 5 } { 1 6 } } P a + { \frac { 1 9 } { 3 2 } } P x - P ( x - a ) + { \frac { 1 } { 2 } } P ( x - 2 a ) .$

Das maximale Biegungsmoment kann nur auftreten:

für $x = 0 , x = a , x = 2 a$ oder $x = 4 a$ . Nun ist

für $x = 0$ : $M = - { \frac { 5 } { 1 6 } } P a ,$

für $x = a$ : $M = { \frac { 9 } { 3 2 } } P a ,$

für $x = 2 a$ : $M = - { \frac { 1 } { 8 } } P a ,$

für $x = 4 a$ : $M = { \frac { 1 } { 1 6 } } P a .$

Der gefährliche Querschnitt ist an der Einmauerungsstelle $A$ , und das maximale Biegungsmoment hat den Wert:

$$M _ { \operatorname* { m a x } } = { \frac { 5 } { 1 6 } } P a$$

Aus der einfachen gesetzmäßigen Form der Gleichungen (b), (c), (d) folgt, daß die Gleichungen der elastischen Linie für die einzelnen Intervalle sich sofort hinschreiben lassen, und somit auch unmittelbar die Gleichungen (e). Es ist daher nicht notwendig, die Rechnungen vollständig durchzuführen. Daß die beiden Konstanten der elastischen Linie gleich Null wurden und von vornherein in Wegfall kamen, hängt natürlich nur mit der Einmauerung bei $A$ zusammen; in anderen Fällen werden sie sich durch die ganze Rechnung schleppen.
